# Ingenium orchestra — учебный сайт

## Запуск
Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Структура
- `index.html` — главная страница
- `pages/` — история, оркестр, галерея, задания, курсовая и отдельные страницы практических работ
- `css/style.css` — общие стили, адаптивная сетка и CSS-логотип
- `js/main.js` — мобильная навигация
- `assets/` — 8 локальных векторных SVG-иллюстраций

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите все файлы и папки проекта в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
6. Через некоторое время GitHub Pages покажет адрес опубликованного сайта.

Все ссылки относительные, поэтому сайт работает и локально, и в GitHub Pages.
